Jak tvořím weby

Čisté HTML, CSS a JavaScript bez zbytečností

Každý web píšu ručně v čistém HTML, CSS a JavaScriptu, bez šablon a těžkých systémů. Zaměřuji se na moderní, přehledné a responzivní weby pro malé firmy, živnostníky a místní služby.

index.htmlobsah a struktura stránky style.cssvzhled, barvy a rozložení script.jsdrobné funkce, třeba menu nebo kopírování kontaktu
Rychlé načítáníWeb obsahuje jen to, co opravdu potřebuje, takže se rychle načte i na mobilních datech.
Dobře vypadá všudeKaždý web ladím pro mobil, tablet i počítač, aby se dal pohodlně číst a ovládat prstem.
Přehledný kódJednoduchá stavba bez složitých systémů. Web se dá snadno upravovat a přenést k jinému hostingu.

Co nedělám: tvořím prezentační weby. Nedělám e-shopy, databáze, přihlašování uživatelů ani administrační systémy, ve kterých by si zákazník web sám spravoval. Úpravy webu za vás rád udělám v rámci úprav nebo měsíční správy.
