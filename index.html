Chci kompletní péči

Jak tvořím weby

Čisté HTML, CSS a JavaScript bez zbytečností

Každý web píšu ručně v čistém HTML, CSS a JavaScriptu, bez šablon a těžkých systémů. Zaměřuji se na moderní, přehledné a responzivní weby pro malé firmy, živnostníky a místní služby.

index.htmlobsah a struktura stránky style.cssvzhled, barvy a rozložení script.jsdrobné funkce, třeba menu nebo kopírování kontaktu
Rychlé načítáníWeb obsahuje jen to, co opravdu potřebuje, takže se rychle načte i na mobilních datech.
Dobře vypadá všudeKaždý web ladím pro mobil, tablet i počítač, aby se dal pohodlně číst a ovládat prstem.
Přehledný kódJednoduchá stavba bez složitých systémů. Web se dá snadno upravovat a přenést k jinému hostingu.

Co nedělám: tvořím prezentační weby. Nedělám e-shopy, databáze, přihlašování uživatelů ani administrační systémy, ve kterých by si zákazník web sám spravoval. Úpravy webu za vás rád udělám v rámci úprav nebo měsíční správy.

Od první zprávy k hotovému webu

Časté dotazy

Na co se lidi ptají

Co je doména a hosting?

Doména je adresa webu, například vasefirma.cz. Hosting je místo na internetu, kde web běží. Obojí se platí zvlášť přímo poskytovateli a cena se liší podle toho, co si vyberete. Předpokládané náklady vám řeknu před začátkem spolupráce a se založením pomůžu.

Jak dlouho to trvá?

Jednostránkový web mívám hotový do týdne od doby, kdy mi pošlete podklady. Firemní web obvykle do dvou týdnů.

Co když se mi návrh nebude líbit?

Upravím ho podle vašich připomínek. Doplatek platíte až ve chvíli, kdy web odsouhlasíte.

Musím mít profesionální fotky?

Nemusíte. Dobře nasvícené fotky z mobilu úplně stačí. Poradím vám, jak je vyfotit.

Můžu si web potom upravovat sám?

Menší úpravy vám rád udělám, teď za úvodní cenu 450 Kč za hodinu (účtuji minimálně 30 minut). Když chcete měnit texty sami, ukážu vám jak.

Jak se platí?

Na začátku zaplatíte zálohu: u jednostránkového webu 1 700 Kč, u firemního webu 3 000 Kč. Doplatek zaplatíte až po dokončení a odsouhlasení webu. Pošlu vám vždy platební odkaz přes Revolut. Zaplatit jde i běžnou kartou, Revolut mít nemusíte. Na vyžádání vystavím fakturu.

Bude web fungovat na mobilu?

Ano. Každý web dělám tak, aby se dobře zobrazoval na mobilu, tabletu i počítači.
